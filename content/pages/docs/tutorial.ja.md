習慣トラッカー **Tally** をデザインします。iPhone の 2 つの画面と 1 ページのウェブサイトを、主にエージェントに頼み、エージェントが見せるものを読みながら作ります。各セクションでは、何を入力またはクリックし、そのあと何が見えるかを説明します。先にエージェントを設定してください（[はじめに](/ja/docs/getting-started/)）。どのバックエンドでもかまいません。

各セクションを終えた時点のプロジェクトは、Silverpoint のリポジトリの `Examples/tutorial/01-start.silverpoint` から `08-handoff.silverpoint` にあります。エージェントが使うのと同じツールで `Examples/tutorial/recipe.sh` が作り直しているので、あるセクションの終わりの状態を開いて、そこから続けられます。

## 1. テンプレートから始める

**ファイル ▸ テンプレートから新規作成 ▸ Mobile App (iPhone screens)** を選びます。空の iPhone フレーム `iPhone 1` と `iPhone 2` が横に並んだドキュメントが開きます。**レイヤー** リストで、それぞれ **Home** と **Habit** に名前を変えてください。エージェントはフレームを名前で探し、このあとの手順も同じです。

![Mobile App テンプレート: キャンバス上の、Home と Habit という名前の空の iPhone フレーム 2 つ](/assets/images/tutorial/01-template.png)

## 2. 最初のターン: スタイル、先に確認、そしてカード

**表示 ▸ エージェントを表示**（⌘J）でエージェントを開きます。入力欄に `/mode ask` と入力して Return を押すと、エージェントはデザインする前に確認するようになります（入力欄のモードメニューに **先に確認** と表示されます。`/mode do` は **すぐに実行** です）。

`/` と入力するとすべてのコマンドが表示されます。続けて次を送信します。

    /style warm-organic Design Tally's Today screen: today's habits, a progress summary and the streaks.

`/style` はこのターンに Warm Organic プリセットを読み込みます。淡いセラドンの上にモスグリーン、Avenir Next の上に Didot です。先に確認では、エージェントはまだ描きません。ターンは **質問カード**「Silverpointエージェントからの質問」で終わり、答えの候補が付いています。カードで選ぶか入力して **送信** を押すか、下の入力欄でそのまま返信してください。

![エージェントパネル: /style のメッセージと、Tally は誰のためのものか、Today で何を先頭にするかを尋ねる質問カード](/assets/images/tutorial/02-question-card.png)

次にエージェントはキャンバスに 3 つの方向性 `Home · Option A`、`B`、`C` をスケッチし、**方向性カード**「Silverpointエージェントからの提案」でターンを終えます。それぞれの方向性に長所と短所が書かれています。気に入ったものをクリックすると、エージェントはそのスケッチを残して、最後までデザインします。

![キャンバスに並んだスケッチした 3 つの方向性と、エージェントパネルの方向性カード](/assets/images/tutorial/02-directions-card.png)

できあがるのはオートレイアウトの Today 画面です。ヘッダー、進捗カード、習慣の行があり、色はすべてスタイルの変数です（`background`、`surface`、`ink`、`muted`、`accent`。それぞれライトとダークの値を持ちます）。

![完成した Today 画面: あいさつ、5 つ中 3 つの進捗カード、3 つの習慣の行](/assets/images/tutorial/02-today.png)

決める前にいろいろ試したいときは、フレームを選択して `/variants 3` を送信します。エージェントはその案を 3 つ横に並べ（元のものとコピー 2 つ、`make_options` で）、それぞれを別の方向に変えます。

## 3. コンポーネントとバリアント

習慣の行はどれも同じ見た目なので、コンポーネントにします。次を送信します。

    Make the habit row a component with two variants, done and to do, and use it for every row. Add walking and "no phone after 10".

エージェントは画面の横に **Habit row** コンポーネントセット `Habit row · Done` と `Habit row · To do` を追加し（バリアントの `state` は `done` か `todo`）、行をそれぞれ独自のラベルとストリークを持つ 5 つのインスタンスに置き換えます。コンポーネントを編集すると、そのインスタンスがすべて追従します。「mark stretching done」と頼むと、エージェントはそのインスタンスを done のバリアントに切り替え（`set_variant`）、ラベルはそのまま残します。

![Habit row コンポーネントセット: チェックが塗られた完了の行と、チェックが輪郭だけの未完了の行](/assets/images/tutorial/03-habit-row.png)

## 4. 変数とテーマ

キャンバスの何もないところをクリックして **デザイン** タブを開きます。何も選択していないとき、その **バリアブル** セクションに **バリアブルとテーマを編集…** があり、スタイルの色が並んでいます。それぞれ `mode` 軸の `light` と `dark` の値を持ちます。**テーマのプレビュー** でキャンバスをどちらかに切り替えられます。

もう 1 つ頼みます。

    Add a streak color, amber in light and a warmer gold in dark, use it for the streak labels, and show the Habit screen in dark.

エージェントはモードごとに値を持つ `streak` を定義し、ストリークのラベルを `$streak` にバインドし、Habit フレームのテーマを `mode: dark` にします。これで両方を一度に見られます。

![ライトテーマの Home、その横のダークテーマの Habit 画面、そして Habit row セット](/assets/images/tutorial/04-themes.png)

## 5. ウェブサイト: オートレイアウトとグリッド

次は同じ変数を使った 1 ページのサイトです。

    Now Tally's one-page website, on the same variables: a hero, the art, three features.

エージェントは幅 1440 の **Site** フレームを追加します。フレームはセクションを縦方向のオートレイアウトで積み重ね、ナビゲーションとヒーローは横方向のオートレイアウトなので、テキストが変わっても間隔が保たれます。3 つの機能は `1fr` の 3 列の **グリッド** に並び、各カードが自分の列を埋めるので、3 つは同じ幅になり、テキストはその中で折り返します。そしてフレームに重なる 12 列のレイアウトグリッドが、もとになったガイドを示します。

![ウェブサイト: Tally のナビゲーション、アートの枠が付いたヒーローの見出し、3 列のグリッドに並んだ 3 つの機能カード](/assets/images/tutorial/05-website.png)

## 6. 批評、デザインレビュー、リント

**デザインレビュー。** 設定 ▸ エージェント ▸ デザインレビュー でレビュー担当のモデルを選びます。それ以降、デザインを変えるターンは、終わるときにその 2 つ目のモデルがレビューします（1 回だけ省くときは、入力欄の **このターンをレビュー** スイッチをオフにします）。セクション 5 のウェブサイトのターンの前にレビュー担当を設定していれば、そのターンは **レビュー中…** のあとレビューの項目「…によるレビュー」で終わり、指摘と **判定: 合格** または **判定: 要修正** が表示されます。要修正のときは、修正のためのターンが 1 回続きます。

![エージェントパネルのレビューの項目: ウェブサイトへの 2 つの提案と、判定: 合格](/assets/images/tutorial/06-design-review.png)

**批評。** Home を選択して `/critique contrast and hierarchy` を送信します。このターンは見るだけです。読み取るツールしか渡されないので、キャンバスは何も変わりません。良い点と問題点（それぞれに修正案付き）を答え、何を変えるかを尋ねる質問カードで終わります。

![/critique のターン: 良い点、修正案付きの 3 つの問題点、そして質問カード](/assets/images/tutorial/06-critique.png)

「Yes, both」と答えると、エージェントは日付と進捗のキャプションを `ink` に暗くします。

**リントと仕上がりの確認。** `/lint` を送信すると、入力欄の上のメモに指摘が表示されます（何も選択していないときは、**デザイン** タブの **デザインチェック** にも **実行** があります）。`/fix-lint` は機械的に直せる修正をすべて適用し、いくつ適用したかと何が残っているかを伝えます。仕上がりの問題は残ります。判断が必要なものなので、自動で直されることはありません。

**バージョン履歴。** ターンはどれもバージョンになります。**ファイル ▸ バージョン履歴…** は日ごとに一覧にします。1 つ選ぶと現在と比べられ、**バージョンを復元** でそれを元に戻せます（**選択したレイヤーを復元** はオンにしたフレームだけ）。**ファイル ▸ バージョンを保存…**（または `/version before shader`）は現在の状態に名前を付けます。

![ウインドウの上のバージョン履歴: エージェントのターンがバージョンとして並ぶ](/assets/images/tutorial/06-version-history.png)

## 7. シェーダーを Claude Code から MCP で

パネルのエージェントは入り口の 1 つで、Claude Code や Codex はもう 1 つの入り口です。**ヘルプ ▸ Claude CodeまたはCodexを接続…** を選ぶと、設定 ▸ MCP にクライアントに追加する設定が表示されます。ドキュメントを開いたまま、Claude Code に頼みます。

    In my open Silverpoint document, put the Mesh Gradient shader preset on Tally's hero art.

Claude Code はパネルのエージェントと同じツールを呼びます。プリセット付きの `list_shaders`、`{"preset": "mesh-gradient"}` を渡す `set_shader`、そして `Hero art` フレームの塗りをそのシェーダーにする `batch_design` です。ウェブサイトのアーチにメッシュグラデーションが入ります。アプリでは、ノードを選択して塗りのペイントメニューで **シェーダー…** を選ぶと、同じことを手作業でできます。

![アーチ形のヒーローのアートをメッシュグラデーションのシェーダーで塗ったウェブサイト](/assets/images/tutorial/07-shader.png)

## 8. ハンドオフ: コード、ガイド、バージョン

Today 画面を選択して **インスペクト** タブを開くと、選択範囲のコードが表示されます。**ファイル ▸ コードまたはトークンを書き出す…**（⌥⇧⌘E）は SwiftUI、HTML などのターゲットを、変数をトークンとして書き出します。

![キャンバスの横のインスペクトタブ: 選択したフレームのコードを表示](/assets/images/tutorial/08-inspect.png)

ハンドオフの前に、開発者向けにドキュメントのガイドを書くようエージェントに頼みます。

    Write the design guide: what Tally is, the variables, the Habit row component, the grid and the type.

続けて `/handoff ~/code/tally`（または **ファイル ▸ ハンドオフ先…**）を送信すると、Silverpoint はそのフォルダにハンドオフのバンドルを書き込みます。メモには書き込んだ場所が表示され、**プロンプトをコピー** で、コーディングエージェントに渡すプロンプトをコピーできます。`/version Hand-off` で、ハンドオフした状態に印を付けます。

## 9. ウェブサイトを公開する

**ファイル ▸ ウェブサイトを公開…** を選びます。**プロジェクト** の下の **選択…** で新しい Inkwell サイト用の空のフォルダを選び、**書き出すファイル** を確認してから **公開** を押します。Silverpoint はインストールされている `inkwell` でサイトをビルドし、**プレビュー** で開きます。
