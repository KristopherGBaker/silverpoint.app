## 動作環境

- **システム:** macOS 26 以降。
- **価格:** ベータの間は無料。

## ダウンロード

[silverpoint.app/download](https://silverpoint.app/ja/download/) からベータ版をダウンロードし、DMG を開いて Silverpoint をアプリケーションフォルダへドラッグします。アプリは公証済みで、自動でアップデートされます。1 日 1 回確認し（設定 ▸ 一般 ▸ アップデート）、**Silverpoint ▸ アップデートを確認…** ですぐに確認できます。

## 最初のデザイン

1. Silverpoint を開きます。初回は起動ウインドウの上に設定シートが開きます。**エージェントを設定** を押し、動かし方を選びます。Claude（お使いの Claude Code 経由）、Codex（お使いの Codex CLI 経由）、API キー、Apple のオンデバイスモデル、ローカルサーバーから選べます。**チェック** で一度だけ試せます。押すまでモデルには何も送られません。どの手順もスキップできます。
2. エージェントに先に確認させるか、任せきりにするかを選び、**試してみる** を押します。新しいデザインが開き、エージェントの入力欄にサンプルの依頼が入ります。準備ができたら送信してください。（完了を押すとシートを閉じます。）
3. 「ポッドキャストアプリの設定ウインドウ」のように次に欲しいものを説明し、キャンバスにフレームが描かれていくのを見てください。変更はすべてバージョン履歴に残るので、いつでも戻れます。
4. 起動ウインドウの **はじめに** チェックリストには、ほかに試してほしいことが 6 つあり、やるたびにチェックが付きます。× で閉じられ、設定 ▸ 一般 ▸ **「はじめに」チェックリストを表示** で戻せます。**ヘルプ ▸ Silverpointへようこそ…** で設定シートをもう一度開けます。
5. 起動ウインドウから開いたデザイン（最近使ったもの、開く…、テンプレート）は起動ウインドウの大きさと位置を引き継ぐので、大きなウインドウにしたいときは先に起動ウインドウを広げてください。最後のドキュメントウインドウを閉じると起動ウインドウが戻ります（設定など、単独で開いたままになるウインドウがあるときは除きます）。**ウインドウ ▸ ホーム**（⌃⌘H）でいつでも表示できます。

[エージェントとの会話](/ja/docs/agent-conversation/)はドキュメントと一緒に保存されるので、ファイルと一緒に持ち運べます。

## Claude Code や Codex を接続する

アプリの **ヘルプ ▸ Claude CodeまたはCodexを接続…** で設定 ▸ MCP が開きます。開いているドキュメントのデザインツールを提供し、クライアントに追加する設定を表示します。

その設定を Claude Code に追加し、開いているドキュメントでデザインするよう頼んでください。

続きは: [スキル](/ja/docs/skills/)でエージェントにあなたのルールを教え、[テンプレートとスタイル](/ja/docs/templates-and-styles/)で新しいドキュメントを始め、[デザインシステムパッケージ](/ja/docs/design-system-packages/)でドキュメント間でコンポーネントを共有できます。
