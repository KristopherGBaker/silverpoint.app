## 2026.46.1

2026 年 11 月 10 日。

ベータの 3 つ目のビルドです。入れるとベータの 60 日がまた始まります。

### このビルドの新機能

- **コンポーザーのスラッシュコマンド。** エージェントパネルで / を入力すると、コマンドが表示されます。/variants、/critique、/fix-lint、/handoff は、ターンの準備をしてくれます。/history、/attach、/export、/new はすぐに実行され、何をしたかを伝えます。ドキュメントに独自のコマンドを持たせることができ、コマンドファイルで自分のコマンドを追加することもできます。
- **変更しない批評。** /critique はデザインを見るだけです。どのバックエンドでも同じです。Claude Code と Codex では、そのターンにデザインを変えられるツールがありません。
- **より細かいデザインレビュー。** レビューは 2 段階で判断し、依頼した内容とデザインを照らし合わせます。エージェントパネルのレビューの項目には、結果、忠実度の表、レビューに使ったペルソナが表示されます。2 ラウンド目では、どの指摘が直ったかが表示されます。まだ残っている指摘は、引き続きブロックします。
- **クラフトチェック。** 9 つの新しいリントルールが、よくある弱点を指摘します。平坦な階層、不揃いな見出しのリズム、長すぎる行、詰まった行間、カードの中のカード、色の上のグレーの文字、グラデーションの文字、アイコン代わりの絵文字、すべて同じ間隔です。これらは助言だけで、**リントの修正** では変更されません。設定では独自のグループにまとめて、英語と日本語で表示されます。

### そのほか

- エージェントはありきたりな見た目を避け、色、サーフェス、インタラクションの状態をより丁寧に計画します。
- ネストしたコンポーネントを含むデザインをエージェントが編集しても、Silverpoint がクラッシュしなくなりました。
- エージェントが動く前に応答がモデルの出力上限に達しても、黙って止まらず、そのまま続けます。
- 長く考える推論モデルでも、デザインレビューが最後まで終えられるようになりました。

## 2026.45.2

2026 年 11 月 8 日。

ベータの 2 つ目のビルドです。入れるとベータの 60 日がまた始まります。

### このビルドの新機能

- **デザインレビュー。** 設定 ▸ エージェントでオンにするか、1 回だけならコンポーザーの**このターンをレビュー**で。デザインを変えたターンのあと、別のモデルがそれをレビューし、直すべきと言われた点をエージェントが最大 2 ラウンドで直します。Claude Code や Codex を含め、どのバックエンドでも使えます。
- **Claude Code と Codex でも「先に確認」。** これらのバックエンドでも、質問や方向性の提案がカードで届き、Silverpoint の問題を報告できます。
- **サイトを選んだ Web 検索。** 設定 ▸ エージェントで、エージェントの Web 検索を指定したサイトに限ったり、指定したサイトを除いたりできます。
- **間隔ガイド。** ドラッグ中、レイヤーが隣との等しい間隔にスナップし、目印と距離が表示されます。
- **ショートカット、Siri、Spotlight。** ショートカットから、フレームの書き出し、バージョンの保存、デザインのチェック、エージェントへの依頼、ドキュメントを開く、コンポーネントの挿入ができます。Spotlight でドキュメントとコンポーネントを探せます。
- **お使いのサービスで画像を。** 画像プロバイダのプラグイン、または OpenAI 互換の画像エンドポイントのカスタムヘッダーと任意のキー。✨ ボタンに画像の費用が表示されます。
- **フォントペアリングとパレットを設定に表示。** パレットはそれぞれ WCAG AA のコントラストを確認します。エージェントがフォントペアリングを保存することもできます。
- **コードの読み込みが広がりました。** iOS のストーリーボードと XIB をフレームとして読み込み、セグエはプロトタイプのリンクになります。SwiftUI の List と `ForEach` は行として読み込みます。
- **デバイス。** 横向きの iPhone Duo のフレームで、システムの帯をどちらの側にも置けます。プロトタイププレーヤーでは、閉じた画面と開いた画面の組を折りたたんだり開いたりできます。
- **すっきりしたツールバー**（図形と描画のメニュー）と、折りたたんだサイドバーをドラッグで引き出せるように。

### そのほか

- コードの書き出し中もアプリが止まらず、時間のかかるプラグインはキャンセルできます。
- 接続した MCP サーバーのパスワードやトークンはキーチェーンに保存されます。
- 画像のトレース、領域の検出、大きなドキュメントの最初のレイアウトでウインドウが止まらなくなりました。
- タイムアウトしたフック、または終了時にまだ動いているフックは、それが起動したものと一緒に終わります。
- 試験的: macOS 27 では、キャンバスを直接タッチで操作できます（選択、移動、サイズ変更、描画、スクロール、ピンチ）。

## 2026.45.1、最初のベータ

2026 年 11 月 5 日。

Silverpoint は、AI デザイナーを内蔵した Mac ネイティブのデザインキャンバスです。画面を説明するとエージェントがキャンバスの上に組み立て、そこから手で直すことも、エージェントとの会話を続けることもできます。ベータの間は無料です。

### このビルドの内容

- **デザインエージェント。** ドキュメントの中にフレーム、コンポーネント、変数を作ります。先に確認してから進めることも、そのまま任せることもでき、1 回のやり取りは 1 回の取り消しで戻せます。動かすモデルはお手持ちのもの: Claude Code や Codex、API キー、Apple のオンデバイスモデル、ローカルサーバー。
- **本物のキャンバス。** オートレイアウト、コンポーネントとバリアント、テキストスタイルと変数、ベクター編集、コメント、プロトタイプ。
- **すべてのバージョンを保存。** チェックポイントに名前を付け、どのバージョンでも今のデザインと並べて、または重ねて比べ、全体を戻すことも一部のフレームだけ戻すこともできます。
- **お使いのエージェントのための MCP サーバー。** Claude Code、Codex など MCP クライアントが、同じツールで開いているドキュメントをデザインできます（設定 ▸ MCP）。
- **パッケージとしてのデザインシステム**、エージェントに教えて確かめる**スキルとリントルール**、保存や書き出しのあとに動く**フック**、**コマンドプラグイン**。
- **Web サイトを公開。** デザインを Inkwell のテーマとして、複数の言語で書き出します。
- **書き出し。** フレームを PNG、PDF、SVG で。コードの書き出しと読み込み（SwiftUI、UIKit、Compose、React、HTML）と Figma の読み込みも動作しますが、ほかの部分ほどテストされていません。粗い部分があるかもしれません。

### 知っておいてほしいこと

- ベータの各ビルドは、ビルドされてから 60 日間使えます。新しいビルドを入れると 60 日がまた始まります。期限を過ぎると、アップデートするまでデザインは読み取り専用で開きます。そのためにファイルが変わることはありません。
- アプリは 1 日 1 回アップデートを確認します。**Silverpoint ▸ アップデートを確認…** ですぐに確認できます。
- 英語と日本語のみです。使えるのは Mac にインストールされているフォントだけです。同期や共同編集はまだありません。
