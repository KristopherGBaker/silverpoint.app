## インストール

1. 上のボタンから DMG をダウンロードして開き、Silverpoint をアプリケーションフォルダへドラッグします。
2. Silverpoint を開きます。初回は短い設定シートが開き、エージェントをどう動かすかを選びます。お使いの Claude Code、Codex CLI、API キー、Apple のオンデバイスモデル、ローカルサーバーから選べます。試すまでモデルには何も送られません。
3. アプリは 1 日 1 回アップデートを確認します。**Silverpoint ▸ アップデートを確認…** ですぐに確認でき、設定 ▸ 一般 ▸ アップデートで自動確認を止められます。

## AI のサブスクリプションは必要ですか？

いいえ。Silverpoint はモデルを同梱も再販もしていません。エージェントは、あなたが選んだモデルで動きます。

- **無料:** Apple のオンデバイスモデル、または Ollama や LM Studio などのローカルサーバー。Mac の外には何も送られません。
- **お使いのサブスクリプション:** ご自身でサインインした Claude Code や Codex CLI。料金はそのプランに含まれます。
- **API キー:** Anthropic、OpenAI、または OpenAI 互換のプロバイダ。料金はプロバイダからあなたに請求されます。Silverpoint は会話ごとのおおよその費用を表示します。

設定 ▸ エージェントでいつでも切り替えられます。

## 試してほしいこと

- エージェントパネルで画面を説明し、キャンバスの上にでき上がっていくのを見る。
- 大きな変更の前にバージョンに名前を付け、バージョン履歴で今のデザインと比べて、必要なものを戻す。
- 設定 ▸ MCP で Claude Code や Codex を接続し、開いているドキュメントをデザインさせる。
- フレームを PNG、PDF、SVG で書き出す。

## 既知の問題

- コードの書き出しと読み込み、Figma の読み込みは動作しますが、ベータのほかの部分ほどテストされていません。粗い部分があるかもしれません。
- 使えるのは Mac にインストールされているフォントだけです。
- 同期や共同編集はありません。ドキュメントはディスク上のフォルダなので、2 台の Mac で同時に開かないでください。
- アプリとこのサイトは英語と日本語のみです。
