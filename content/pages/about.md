## About

Silverpoint is a native Mac design canvas with an AI designer built in. It is free while it is in beta.

## What the app sends

- **To the model you choose.** When you send a message, your request and the parts of the document the agent needs go to the model you picked in setup: your Claude Code or Codex (which talk to their own services), the provider of your API key, or nothing at all with Apple's on-device model or a local server.
- **To silverpoint.app.** Once a day the app asks this site whether there is a newer build. Settings ▸ General ▸ Updates turns that off.
- **To the image provider you set up** in Settings ▸ General ▸ Images, only when you or the agent generate an image.
- **To Figma**, only when you import a Figma file by its link.

Silverpoint has no analytics and no account. API keys stay in your Mac's Keychain, and your documents stay on your disk.

## This site

This site sets no cookies and has no analytics. It is hosted on GitHub Pages, which keeps its own server logs.
